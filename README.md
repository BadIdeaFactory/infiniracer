# infiniracer
Vanilla JS top-down vector racer in the spirit of 1979 Asteroids. Procedural   infinite track that flares and pinches; anti-magnetic edges catch slow drift   but let fast runs punch through. Camera zooms out with speed. Score = speed ×   distance. Slow-mo wireframe debris explosion on crash. HTML + CSS + JS, zero   deps.
